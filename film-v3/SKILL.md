# 浓郁胶片 v3

使用 `scripts/grade.py` 执行本技能。配方以经典负片式反差为灵感，暗部更深，中间调反差更强，高光平滑收束。阴影明显偏青蓝，高光偏奶油金色。绿叶收向橄榄灰，蓝色偏青，红色相对保留饱和度。暖肤色区域减弱调色幅度，颗粒随亮度渐变。

## 读取直接上传的照片

- 优先处理用户直接上传的 `.cr2`、`.jpg` 或 `.jpeg` 文件，扩展名不区分大小写，接受一次上传多张。有工作区路径时直接读取。附件给出 `sediment://file_…` 时，通过 `download_file` 传入文件 ID，使用工具返回的路径。处理前确认路径可读，随后逐张直接调用调色脚本，并按上传顺序显示成片。
- 聊天中能看到图片但没有附件标识或可读路径时，先核查当前上传是否已出现在工作区。若只收到预览，请用户用「上传文件」直接选择同一张 CR2 或 JPG，并在发送前确认出现带文件名的附件卡片。如果传输工具明确返回大小限制，按实际错误说明限制。
- ZIP 仍可作为批量上传的可选方式，仅提取用户指定范围内的照片。

## 执行

1. 从用户指定的原始文件开始。一批照片逐张处理，始终从原图开始，避免重复叠加配方。默认保留构图、像素尺寸和正确方向。
2. 从本技能目录运行 `python scripts/grade.py /path/to/source.jpg /path/to/source-film-v3.jpg`。输出用新路径，脚本会拒绝覆盖已有文件。依赖见 `requirements.txt`。常规输入支持 JPEG、PNG、TIFF，输出为带 sRGB 配置文件的 8 位 JPEG、PNG 或 TIFF。JPEG 以质量 96 和 4:4:4 采样输出。已用 JPEG 和 Canon CR2 验证。RAW 使用 rawpy 从传感器数据解码，采用相机白平衡，按实际画面方向输出。RAW 显影与相机直出 JPEG 的起点可能不同。
3. 核对原图与成片的方向、尺寸、面部肤色、冷暖过渡和明暗细节。检查全尺寸下颗粒是否干扰面部或暗部。如果用户确认要调整风格，以原图重新渲染并说明实际改动。
4. 完成调色后按下方流程把每张成片直接显示在聊天中。用户要比较时，显示带清晰标记的原图与成片对照。

## 在聊天中显示成片

- 从最终成片文件制作聊天预览。用 Pillow 的 `thumbnail((1600, 1600), Image.Resampling.LANCZOS)` 等比例缩小，保留方向和嵌入的 sRGB 配置。预览另存为 JPEG，原始成片保留全尺寸。
- 结束回复前，将每张预览通过聊天的图像输出发送。当前 Codex 环境在 `functions.exec` 中调用 `view_image` 并用 `image()` 输出实际图像块。多张照片按上传顺序发送，每张实际输出一个图像块。示例：

  ```javascript
  const preview = await tools.view_image({path: "预览图片的绝对路径"});
  image(preview.image_url);
  ```

- 供自己检查用的图片读取、文本文件路径和 ZIP 都不能代替聊天图像输出。若当前客户端没有可用的图像输出能力，明确说明，并在可用时提供成片附件。只在确实交付了可下载文件时报告下载。
- 随图简述使用的配方。用户只要原尺寸时，在可用的交付目录提供全尺寸成片附件。

## Python 环境

先检查能否导入 NumPy、Pillow 和 rawpy。当前云端工作区若存在 `/workspace/work/film-v3-runtime/bin/python`，可以直接用它调用脚本。其他环境若缺依赖，在可写目录创建虚拟环境，用该环境的 Python 运行 `-m pip install -r <技能目录>/requirements.txt`，再用同一个 Python 执行调色。
